# VSPA-PE-Vibrotactile-Finger-Localization-v1.8
A five-channel Linear Resonant Actuator (LRA) haptic system for finger localization and adjacent-finger recognition. Version 1.8 implements randomized, balanced self-study experiments comparing 2-second and 4-second stimulation intervals using Python, Arduino Uno R3, TCA9548A, and DRV2605L controllers.
